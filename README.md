# 青共校刷题 · 第49期

苏州科技大学青共校学习材料刷题网页，单文件、离线可用。
内置 104 道题：单选 46、多选 46、简答 12，按 9 个考点归类。

## 在线使用

https://vedal451.github.io/gqx/

手机浏览器打开后，在菜单里选择「添加到主屏幕」，即可像 App 一样使用。
也可以下载 `index.html` 双击打开，离线刷题。

## 功能

- 分题型刷题：单选 / 多选 / 简答
- 分考点刷题：党的二十大精神、党史国史、团史团务等 9 个考点
- 答案速览表 + 关键词搜索 + 简答要点比对
- 错题本、收藏、随机 20 题、限时挑战（20 题 / 15 分钟）
- 掌握率 / 正确率统计，薄弱考点排序，深色模式
- 手机手势：左右滑动切题；滑到页面底部继续上滑 = 下一题，顶部下滑 = 上一题
- 题库管理：导入新的 Word / JSON，一键更换题库

## 更换题库

打开「我的 → 题库管理」：

- **导入 Word**：选新的 `.docx`，浏览器本地解析，不上传
- **导入 JSON**：选题库数据文件（可由「导出当前题库」得到）
- **从链接读取**：默认读本仓库的 `bank.json`，也可以填其它地址

流程：预览（题量、前 3 题、格式提醒）→ 确认替换 → 自动刷新。
替换前会按题目内容匹配，能对上的做题记录继续保留；对不上的清除。
随时可以「恢复内置题库」，也可以「导出当前题库」备份或发给别人。

### 标题跟着题库变

首页顶部的「第49期 · 苏州科技大学」会自动从新题库的**文件名 + 开头几段**里识别「第X期」和「XX大学」。
识别不到（或识别错）时，在导入预览的「显示名称」里手动改一次即可。

## 注意事项

### 1. Word 格式要求

解析器认的是这套结构，缺一不可：

```
一、单选
二、多选
三、简答题
答案解析
```

- 答案区也要有同样三个小标题，答案**按题目顺序**一条一题
- 选项为 `A.` `B.` `C.` `D.` 四个，答案为字母（多选如 `BCD`）
- 题干编号可有可无，`1.` `51.` 会自动去掉
- ①②③④ 材料行会保留并渲染

### 2. 目前不支持的题型

- 判断题（√ / ×）、填空题
- 五选一（E 选项）
- 答案分散在每道题后面、或在表格里

遇到这些会在导入预览里给出提醒；数量对不上会直接失败，不会覆盖旧题库。
如果有需要，把样本文档发出来，可以再适配。

### 3. 考点是自动归类的

导入的题库会按关键词自动归到 9 个考点，归不上的进「未分类」。
如果新题库是全新主题（例如宪法、校规），可能出现大量「未分类」，分考点复习会变粗；
需要的话可以补充「考点 → 关键词」规则。

### 4. 学习记录怎么对应

记录跟着**题干文字**走，不跟题号走：

- 只在末尾追加题目 → 旧记录全部保留
- 中间插入/删除 → 后面的题干错位，对不上的记录会被清除
- 换浏览器、清缓存、无痕模式 → 记录会丢
- 记录只存本机，不跨设备；换设备请用「我的 → 导出 / 导入」

### 5. 浏览器要求

- 导入 Word 需要浏览器支持 `DecompressionStream`（Chrome、Edge、较新的小米/华为浏览器都支持）
- **微信内置浏览器（X5 内核）可能提示“不支持解压”**，请在系统浏览器里打开再导入
- 「从链接读取」需要联网；本地 `file://` 打开时该功能不可用

## 常见问题

**导入时提示“没找到「一、单选 / 二、多选 / 三、简答题 / 答案解析」”**
文档结构或标题文字不一致，按上面的格式改一下，或发出来适配。

**提示“单选题 46 道，答案 45 条，数量不一致”**
答案区漏了一条或多了一条，补齐即可。

**导入后顶部还是「第49期」**
文件名和正文里都没有识别到期数，在导入预览的「显示名称」里手动填。

**想回到最初的题库**
题库管理 → 恢复内置题库（能对上的记录会保留）。
