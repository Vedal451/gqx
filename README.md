# 青共校刷题 · 第49期

苏州科技大学青共校学习材料刷题网页，单文件、离线可用。
共 104 道题：单选 46、多选 46、简答 12，按 9 个考点归类。

## 在线使用

开启 GitHub Pages 后访问：

https://vedal451.github.io/gqx/

手机浏览器打开后，在菜单里选择「添加到主屏幕」，即可像 App 一样使用。

## 功能

- 分题型刷题：单选 / 多选 / 简答
- 分考点刷题：党的二十大精神、党史国史、团史团务等 9 个考点
- 答案速览表 + 关键词搜索 + 简答要点比对
- 错题本、收藏、随机 20 题、限时挑战
- 掌握率 / 正确率统计，深色模式，手机与电脑自适应
- 手势翻题：左右滑动切题，滑到底部继续上滑也能到下一题

## 更换题库

打开「我的 → 题库管理」：

- **导入 Word**：选新的 `.docx`（保持「一、单选 / 二、多选 / 三、简答题 / 答案解析」结构）
- **导入 JSON**：选题库数据文件
- **从链接读取**：默认读本仓库的 `bank.json`

导入前会显示题量、前 3 题和格式提醒；确认后自动保留能对上的做题记录。
也可以随时恢复内置题库或导出当前题库。

## 本地使用

下载 `index.html`，双击用浏览器打开即可，无需联网、无需安装。

## 数据说明

学习记录保存在浏览器本地（localStorage），不上传服务器；可在「我的」中导出 / 导入。

## 题库来源

《附件1+第49期青共校学习资料》，答案与解析均按原文整理，仅供学习使用。
